# LifeLink – Donor Connection Android App

LifeLink is an Android application designed to connect donors and recipients efficiently using modern mobile technologies.  
The app focuses on accessibility, ease of use, and real-time data handling to improve donor discovery and communication.

# Overview

LifeLink helps users find and connect with donors based on location and availability.  
It is built using Android best practices with Kotlin and integrates cloud services for authentication and data management.

# Features

- User authentication (Firebase)
- Donor and recipient registration
- Location-based donor discovery
- Real-time data updates
- Clean and user-friendly UI
- Secure handling of user data

# Tech Stack

- Language:** Kotlin  
- IDE:** Android Studio  
- Backend:** Firebase  
- Database:** Firebase Realtime Database / Firestore  
- Maps & Location:** Google Maps API  
- Version Control:** Git & GitHub
